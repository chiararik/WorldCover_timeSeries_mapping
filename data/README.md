# Data

## Overview

This directory does not contain raw data (rasters and CSVs are too large for GitHub).
All inputs and outputs are described below with download/generation instructions.

## Inputs required

### Landsat imagery (via Google Earth Engine)
Accessed automatically by the GEE script from USGS Collection 2 Tier-1 Level-2:
- `LANDSAT/LT04/C02/T1_L2` (Landsat 4)
- `LANDSAT/LT05/C02/T1_L2` (Landsat 5)
- `LANDSAT/LE07/C02/T1_L2` (Landsat 7)
- `LANDSAT/LC08/C02/T1_L2` (Landsat 8)
- `LANDSAT/LC09/C02/T1_L2` (Landsat 9)

### Sentinel-1 (via Google Earth Engine, post-2014)
- `COPERNICUS/S1_GRD` — IW mode, VV+VH polarisation

### Ancillary datasets (via Google Earth Engine)
| Dataset | GEE ID | Variables |
|---|---|---|
| SRTM | `USGS/SRTMGL1_003` | Elevation, slope, roughness |
| MERIT Hydro | `MERIT/Hydro/v1_0_1` | Upstream drainage area (for TWI) |
| TerraClimate | `IDAHO_EPSCOR/TERRACLIMATE` | tmmn, tmmx, def, vap, soil |
| ESA WorldCover 2020 | `ESA/WorldCover/v100` | Training labels |
| FAO GAUL Level-2 | `FAO/GAUL/2015/level2` | AOI boundary |

## GEE outputs (per year, exported to Google Drive)

These files are generated by `gee/wetland_classification.js` and consumed by the R pipeline:

```
gee_outputs/
├── land_cover_YEAR.tif         ← primary classified map (Int16)
├── confidence_YEAR.tif         ← max RF class probability × 100 (Byte)
├── multiprob_YEAR.tif          ← per-class RF probabilities (N bands, Byte)
├── accuracy_YEAR.csv           ← validation metrics
├── validation_points_YEAR.csv  ← per-point probabilities (for calibration)
├── variable_importance_YEAR.csv← RF feature importance
├── class_lookup_table.csv      ← class code ↔ name mapping (one file)
└── jm_distances.csv            ← JM separability matrix (one file)
```

## Study area

- **Area**: Ibaji LGA, Kogi State, Nigeria
- **Total extent**: 2,281.8 km²
- **Coordinates**: approximately 6.5–7.1°N, 6.5–7.1°E
- **Boundary source**: FAO GAUL 2015, Level 2, `ADM2_NAME = 'Ibaji'`
